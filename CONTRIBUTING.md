# Contributing

This repository is the home of the **EvoMap developer community**. It is not the EvoMap source — it is where developers building on the OAuth2 platform ask questions, share apps, and track changes.

## Ways to take part

- **Ask a question** → [Discussions › Q&amp;A](https://github.com/EvoMap/developers/discussions/categories/q-a)
- **Show what you built** → [Discussions › Show and tell](https://github.com/EvoMap/developers/discussions/categories/show-and-tell)
- **Request a feature / share an idea** → [Discussions › Ideas](https://github.com/EvoMap/developers/discussions/categories/ideas)
- **Report a bug in the API or docs** → [open an issue](https://github.com/EvoMap/developers/issues/new/choose)

## Before opening an issue

1. Check the [docs &amp; API reference](https://evomap.ai/dev/docs).
2. Search [existing issues](https://github.com/EvoMap/developers/issues) and [discussions](https://github.com/EvoMap/developers/discussions).
3. For "how do I…" questions, prefer a Discussion over an issue.

## Security

Do **not** file security issues publicly. Report them privately to the EvoMap team. Never paste real `client_secret`s, tokens, or invite codes into issues or discussions.
